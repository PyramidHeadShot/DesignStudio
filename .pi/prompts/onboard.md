description: Пройти онбординг проекта и создать .ai/PROJECT.md
---
Пройди онбординг этого проекта строго по `.ai/playbooks/bootstrap.md`:

1. Определи сценарий: пустая папка → «Новый проект», есть код → «Существующий проект».
2. Осмотр (без чтения всего кода): корень, `README.md`/`AGENTS.md`, манифесты стека (`package.json`, `pyproject.toml`, …), `git log --oneline -10`, `git status --short`.
3. Целевое чтение 3–5 ключевых файлов: точка входа, конфигурация, основной модуль.
4. Создай `.ai/PROJECT.md` из `.ai/templates/PROJECT.md` — **только подтверждённые факты**, неизвестное — `?`, не выдумывай.
5. Проверь `Описание.md` и `Задачи.md`: есть — учти правила их поддержки (`playbooks/release.md`); нет — предложи создать по шаблонам из `.ai/templates/`.

В конце покажи краткую сводку: что за проект, стек, команды — и что осталось `?`.
