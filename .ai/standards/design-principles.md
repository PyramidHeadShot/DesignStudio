# Дизайн-стандарты сайта — сверяться при любой работе над UI

> Зафиксировано по результатам исследования (2026-01): тренды Design Shack «30+ Portfolio Design
> Trends for 2025», живой разбор pentagram.com, сравнение Astro vs Next.js 2025.
> Это не абстрактные пожелания — чек-лист: каждое правило проверяется при ревью страницы.

## Референс: что делает pentagram.com (проверено вживую)

- Главная — плотная сетка работ: ~259 ссылок на кейсы и ~449 изображений; всё остальное вторично.
- Один шрифт (Plain), ни одного декоративного акцента; ч/б палитра.
- Фильтр по категориям (Brand Identity, Digital…) — главный инструмент навигации.
- Технически кастомный бандл без фреймворка-маркеров (Next/Astro) — студии такого уровня
  строят сайт руками; нам не нужно копировать эту часть, только принципы.

## Правила (чек-лист страницы)

1. **Show, don't tell** — работы первыми, текст минимальный. Герой-экран = работа, а не описание студии.
2. **Curated homepage** — курируемая выборка лучших кейсов на главной; без бесконечного скролла.
3. **Типографика как главный дизайн** — один-два гротеска, крупный кегль, ритм сетки вместо декора.
4. **Motion = WOW** (скорректировано 2026-09-26: снято ограничение «только микроанимации») — анимация полноценный слой дизайн-идентичности студии; сайт обязан производить «вау-впечатление»: мы дизайн-студия, и подача — наш продукт. Разрешено и приветствуется: expressive-переходы и timeline-хореография страниц (hero, кейсы), кинетическая типографика, FLIP-переходы сетки при фильтрации, SVG-draw/морфинг акцентов, scroll-linked детали, spring-микровзаимодействия. Инструмент — anime.js (см. «Технические следствия»). Рамки разумного: один motion-язык (единая кривая/ритм, длительность 150–900 мс), эффект раскрывает работу и типографику, а не спорит с ними; никакого motion ради motion; обязательные `prefers-reduced-motion` (полный freeze) и читаемость контента без JS.
5. **Монохром + 1 акцент** — ч/б база; цвет только для интерактивных состояний.
6. **Кейс = сторителлинг** — страница кейса: задача → процесс → результат; 3–6 экранов, крупные изображения.
7. **«Почти брутализм»** — смелость и прямота без отталкивающей грубости.
8. **Скорость = дизайн, но WOW важнее цифр** (скорректировано 2026-09-26) — Lighthouse: жёсткий минимум **85**, цель 90+. Бюджет motion-слоя: бандл анимаций ≤ 25 КБ gzip; animировать только transform/opacity (и SVG без layout-пересчётов); контент и изображения не жертвовать. По-прежнему: тормозящий сайт противоречит позиционированию.
9. **Персональность** — живой тон текстов, фото/голос студии, контакты без трения.

## Технические следствия из правил

- Фреймворк: **Astro + MDX**, JS — точечные islands. Motion-слой — **anime.js** (единственная анимационная библиотека проекта; tree-shaken core ≤ 25 КБ gzip). Islands анимаций допускаются и на главной, и на страницах кейсов. Железное: контент читается без JS (progressive enhancement), `prefers-reduced-motion` -> полный freeze.
- Изображения: `astro:assets` (`<Image>`) — автоматические форматы/размеры, `loading`/`decoding` по позиции.
- Вёрстка: чистый CSS Grid, mobile-first; семантические теги, alt на все изображения, контраст WCAG AA.
- Никаких UI-библиотек (Tailwind/Bootstrap) — минимализм держится на типографике и сетке.
- Шрифт: системный или один self-hosted гротеск; subsetting; `font-display: swap`.
