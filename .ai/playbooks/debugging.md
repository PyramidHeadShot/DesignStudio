# Playbook: диагностика

Цикл: воспроизвести → локализовать → понять причину → исправить минимально.

## Порядок

1. **Точная ошибка**: полный текст/стек-трейс целиком. Пользователь пересказал — попроси вывод или возьми из логов.
2. **Воспроизведение**: команда/шаги, дающие ошибку стабильно. Не чини то, что не воспроизвёл.
3. **Локализация**: от точки падения вверх по стеку → найди код. `grep`/поиск символов по репозиторию, а не догадки.
4. **Причина ≠ симптом**: symptom «500 в API», причина «nullable колонка без миграции». Чини причину.
5. **Минимальный фикс** + проверка: воспроизведение больше не срабатывает, смежные сценарии целы (тесты/компиляция).

## Красные флаги — остановись и подумай

- Правка «наугад» не помогла дважды → выпиши гипотезы, проверь их по коду/логам по одной.
- Фикс требует >3 несвязанных изменений → вероятно, неправильно определена причина.
- Проблема только на среде пользователя (прод/его машина) → проверь различия окружения (env, версии, пути), а не меняй код вслепую.
