# Playbook: онбординг в проекте

Сначала определи сценарий:

- **Проект пуст (нет кода)** → сразу к разделу «Новый проект». Анализировать нечего — не запускай осмотр.
- **Есть код** → сценарий «Существующий проект» ниже.

## Новый проект (пустая папка)

1. Уточни у пользователя: назначение, стек (если выбран), требования. Не навязывай стек без обсуждения.
2. Создай каркас проекта по ответам (scaffold, git init, `.gitignore`, `.env.example`).
3. Заполни `.ai/PROJECT.md` из `templates/PROJECT.md` **только подтверждёнными фактами**: стек, команды, структура — по мере того, как они реально появились. Неизвестное — `?`.
4. Дальше правило одно: изменил стек/команды/структуру → обнови карточку в том же коммите.

## Существующий проект

Цель — за минимум шагов собрать контекст и зафиксировать его в `.ai/PROJECT.md`.

## Шаг 1. Осмотр (быстро, без чтения всего кода)

```bash
ls                                # корень: что за проект
cat README.md AGENTS.md 2>/dev/null   # заявленное назначение
cat package.json pyproject.toml go.mod Cargo.toml 2>/dev/null  # стек и скрипты
git log --oneline -10             # свежие изменения и стиль коммитов
git status --short                # незавершённая работа
```

## Шаг 2. Целевое чтение

По результатам осмотра — 3–5 ключевых файлов: точка входа, конфигурация, основной модуль. Не читай подряд всё.

## Шаг 3. Карточка проекта

Скопируй `.ai/templates/PROJECT.md` → `.ai/PROJECT.md` и заполни по фактам из осмотра. Всё, что не выяснил, — пометь `?`, не выдумывай.

В «Соглашениях проекта» отметь пользовательские файлы: если есть `Описание.md` — укажи его и правило поддержки (см. `playbooks/release.md`); если нет — предложи создать по `templates/OPISANIE.md`. Аналогично для `Задачи.md` (шаблон — `templates/ZADACHI.md`).

## Шаг 4. Проектный AGENTS.md (опционально)

Если корневой `AGENTS.md` — универсальный роутер, а проект командный/долгоживущий, предложи пользователю сгенерировать проектный по `.ai/templates/AGENTS-project.md`.

## Правило (оба сценария)

`.ai/PROJECT.md` — живой документ: изменил стек/команды/структуру → обнови карточку в том же коммите.
