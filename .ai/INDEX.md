# .ai — карта служебных файлов агента

Единственная точка навигации по контексту агента. Читай только нужный файл — не загружай всё сразу.

| Задача | Файл | Когда читать |
|--------|------|--------------|
| Базовые правила поведения | [`rules.md`](rules.md) | Всегда актуальны; перечитай при сомнении |
| Порядок работы над задачей | [`workflow.md`](workflow.md) | Перед любой нетривиальной задачей |
| Онбординг в новом/чужом проекте | [`playbooks/bootstrap.md`](playbooks/bootstrap.md) | Первый раз в проекте |
| Тесты: запуск и написание | [`playbooks/testing.md`](playbooks/testing.md) | Работа с тестами |
| Диагностика багов | [`playbooks/debugging.md`](playbooks/debugging.md) | Что-то сломалось, причина неизвестна |
| Коммиты, ветки, релиз | [`playbooks/release.md`](playbooks/release.md) | Фиксация и публикация изменений |
| Дизайн-стандарты сайта | [`standards/design-principles.md`](standards/design-principles.md) | Любая работа над UI сайта: чек-лист правил, референс pentagram, выбор стека |
| Карточка проекта | [`templates/PROJECT.md`](templates/PROJECT.md) | Шаблон; заполняется при онбординге → `.ai/PROJECT.md` |
| Шаблон проектного AGENTS.md | [`templates/AGENTS-project.md`](templates/AGENTS-project.md) | Создание/обновление AGENTS.md конкретного проекта |
| Шаблон описания для пользователей | [`templates/OPISANIE.md`](templates/OPISANIE.md) | Создание/поддержка `Описание.md` в корне проекта |
| Бэклог задач | [`templates/ZADACHI.md`](templates/ZADACHI.md) | Файл `Задачи.md` в корне: пользователь пишет/просит агента; агент выполняет и отмечает статусы |
| Субагенты и MCP (только pi) | [`.pi/README.md`](../.pi/README.md) | Делегирование browser/server/docs/test-агентам; настройка MCP-серверов |
| Установить скилл (не хватает навыка) | [`.agents/skills/skill-installer/`](../.agents/skills/skill-installer/SKILL.md) | Задаче может закрыть готовый скилл; установка — только с согласия пользователя |
| README для человека | [`README.md`](README.md) | Агенту не нужен: инструкция пользователя по установке и обновлению комплекта |

## Состояние проекта

| Файл | Статус |
|------|--------|
| `.ai/PROJECT.md` | Создаётся агентом при онбординге (из `templates/PROJECT.md`). Есть? Читай первым. |
| `AGENTS.md` (корень) | Универсальный роутер. В проектных репозиториях заменяется по `templates/AGENTS-project.md`. |

## Правила поддержки этой папки

- Каждый факт живёт в одном файле; в других — ссылка, не копия.
- Изменял код проекта → обнови затронутые файлы `.ai/` в том же коммите.
- Не создавай новые файлы без записи в эту таблицу.
