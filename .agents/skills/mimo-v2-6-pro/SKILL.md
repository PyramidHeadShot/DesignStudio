# MiMo-V2.6-Pro — мини-справка

## Что это
Флагман **Xiaomi MiMo-V2.6-Pro**: ~1 трлн параметров (MoE), **омни-модальность**
(текст / изображения / аудио), контекст **1M токенов**. В нашей сборке — **дирижёр**
(main-модель) на `provod/mimo-v2.6-pro`.

Семейство: `mimo-v2.6-pro` (флагман) · `mimo-v2.6-flash` (дешёвый баланс) ·
`mimo-v2.6-pro-ultraspeed` (до 20× быстрее, ×10 цена).

## Ключевые параметры (офиц. гайд Xiaomi + гайд провайдера)

| Параметр | Дефолт | Диапазон | Важно |
|---|---|---|---|
| `temperature` | **1.0** | 0–1.5 | ⚠️ **В thinking-режиме ИГНОРИРУЕТСЯ** — модель сама ставит 1.0 |
| `top_p` | **0.95** | 0.01–1.0 | ⚠️ **В thinking-режиме ИГНОРИРУЕТСЯ** — сама ставит 0.95 |
| `max_completion_tokens` (в pi = `maxTokens`) | 1024 | **1024–128000** | 🎯 **КЛЮЧЕВОЙ** для размышлений |
| `frequency_penalty` | 0 | −2..2 | 0.1–0.5 против повторов |
| `presence_penalty` | 0 | −2..2 | малые «+» для разнообразия |
| `stream` | false | true/false | `true` для интерактивных чатов |
| `stop` | null | ≤4 seq | |

> Официальный tip по `max_completion_tokens` дословно: *«для сложных reasoning-задач
> ставьте ВЫШЕ — дать модели достаточно места под размышление»*. Дефолт 1024 — катастрофически
> мало для размышлений. У `temperature`/`top_p` — «меняй либо одно, либо другое, не оба».

## «Прерывание размышления» — головная боль этой модели
Симптом: размышление (thinking) обрезается прямо перед ответом → приходится переспрашивать
по несколько раз, и это сжигает деньги. Запрос при этом часто `200`, страдает именно
блок размышлений (`finish_reason: length`).

Причина: **`maxTokens` слишком мал** → размышление + ответ не умещаются в общий потолок
вывода, и всё обрезается.

Лечение (у нас уже настроено):
- `models.json` → `maxTokens: 128000` (потолок Pro по офиц. гайду).
- `settings.json` → `thinkingBudgets: { high: 32768, max: 48000 }` — бюджет под черновик
  (без него pi сам режет thinking на 16k для уровня `high`).
- Уровень размышления: `/thinking` → `high` или `max`.
- Помни: за `maxTokens` платишь только за реально сгенерированные токены, сам лимит бесплатен.

## Наш конфиг (`dot-pi-agent/models.json` → `provod/mimo-v2.6-pro`)
```json
"reasoning": true,
"thinkingLevelMap": { "minimal": null, "low": "low", "medium": "low", "high": "high", "xhigh": null, "max": "max" },
"contextWindow": 1048576,
"maxTokens": 128000,
"input": ["text", "image"]
```
`reasoning: true` обязательно — без него pi считает модель не-reasoning и не обрабатывает
поток размышлений (внешне выглядело как «0 вывода» + отмена запроса).

## Лимиты изображений (проверено на живой сессии)
Максимум **4 изображения на запрос**, 5-е → 400. Обязателен
`inputLimits.images.resize` (1568×1568, JPEG q75) — см. скилл `image-context-limits`.
