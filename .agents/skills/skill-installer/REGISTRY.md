# Реестр скиллов

Каталог проверенных коллекций скиллов + журнал установок в этом проекте.
Пользуясь каталогом — через skill-installer (`../skill-installer/SKILL.md`):
он обеспечит согласие пользователя, ревью содержимого и регистрацию установки.

## Каталог: проверенные коллекции и пакеты

| Коллекция / пакет | Источник | Что даёт | Доверие |
|-----------|----------|----------|---------|
| Anthropic Skills | `https://github.com/anthropics/skills` | Официальные скиллы Anthropic: работа с документами (docx, pdf, pptx, xlsx — создание/правка/анализ), builder-скиллы | Официальные |
| Superpowers | `https://github.com/obra/superpowers` | Навыки процесса: TDD, систематическая отладка, планирование, code review, brainstorming | Community, широкая известность |
| @narumitw/pi-sync | `pi install npm:@narumitw/pi-sync` | Кросс-машинная синхронизация настроек pi, `AGENTS.md` и опционально сессий через Git/WebDAV/R2/S3. Снапшоты, скан секретов, откаты. Сессии выключены по умолчанию (включать с privacy-аккомодацией). Дополнение к `scripts/session-cwd.mjs` (переносит файлы, но не перебиндивает cwd) | Community, активная разработка (проверено 2025-09-14) |

Правила каталога:

- Источник добавляется только после проверки человеком (или агентом с ревью пользователем).
- В таблице — коллекции (в репозитории обычно `skills/<name>/`) и npm-пакеты (ставятся целиком командой из колонки «Источник»).
- Pin-версия фиксируется на уровне установки (SHA в журнале ниже), а не в каталоге.

## Установлено в проекте

> Журнал ведёт skill-installer. Формат: `- [ ] <name> — <дата> — <источник> — SHA <sha>` → после ревью `[x]`.
