# .agents/skills — универсальные скиллы

Папка для **скиллов, которые понимают любые агенты** (tool-agnostic конвенция).

Pi читает её нативно: проектная `.agents/skills/` в cwd и во всех родительских папках
до корня git-репозитория. Туда же кладутся скиллы, установленные через
skill-installer (см. `skill-installer/SKILL.md`).

## Как pi здесь ищет скиллы

- **Папка с `SKILL.md`** — обнаруживается рекурсивно (основной способ):
  `имя-скилла/SKILL.md` + ресурсы рядом с ним.
- Корневые `.md`-файлы без валидного skill-frontmatter **молча игнорируются** —
  поэтому этот README безопасно лежит здесь.
- Frontmatter `SKILL.md` должен содержать как минимум `name` и `description`.

## Соглашения

- Один скилл = одна папка: `имя-скилла/SKILL.md` (+ необязательные ресурсы).
- Имя папки = имя скилла, нижний регистр, через дефис.
- Скачанные скиллы коммитьте вместе с проектом (это командный артефакт) —
  либо добавьте в `.gitignore`, если считаете их личными; правило одно для всей команды.
- Установка новых скиллов — только через skill-installer (согласие пользователя,
  ревью содержимого). Вручную — тоже можно, но не забывайте про ревью.

## Другие харнессы

Claude Code читает свои скиллы из `.claude/skills/`, Codex — из `~/.codex/skills/`.
Если в команде несколько harness'ов, проще всего добавить эти папки в настройки
соответствующего инструмента как дополнительные источники — содержимое
`.agents/skills/` универсально (это обычный `SKILL.md` + ресурсы).
